## Information We Collect

This extension collects the following information:

- Task metadata (title, due date, course name, URL)
- Data available from Google Classroom and Google Calendar APIs within the scope of the user's authorization

## Purpose of Use

We use the collected information to:

- Display tasks on the WebClass page
- Sync Google Classroom assignments
- Add tasks to Google Calendar

## Storage and Retention

- Storage location: Firebase Firestore
- Retention period: Until the user deletes the data

## Third-Party Sharing

We do not share collected data with third parties.

## Security

Access to stored data is restricted to authenticated users through Firebase security rules.
